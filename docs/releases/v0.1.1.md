# French Holidays v0.1.1 — Première publication

Intégration native Home Assistant issue du portage du module [node-red-french-holidays](https://github.com/tataille/node-red-french-holidays). Elle fonctionne sans Node-RED ni MQTT.

## Fonctionnalités

- Configuration graphique de l’académie et de la région des jours fériés, indépendamment.
- 23 entités : jours fériés, vacances scolaires, dates, compteurs, week-end, jour ouvré et informations de configuration.
- Icônes et libellés en français et en anglais.
- Calendriers officiels, actualisation quotidienne, recalcul à minuit et cache persistant.
- Icône et logo embarqués pour Home Assistant 2026.3 et plus récent.
- README illustré, guide utilisateur et table de correspondance avec Node-RED.

## Installation

**HACS** : ajouter `tataille/homeassistant-french-holidays` comme dépôt personnalisé de type Intégration, télécharger puis redémarrer Home Assistant.

**Manuelle** : télécharger `homeassistant-french-holidays-v0.1.1.zip`, puis copier `custom_components/french_holidays` dans `/config/custom_components/` et redémarrer Home Assistant.

Ajouter ensuite French Holidays depuis Paramètres → Appareils et services. Nantes et Martinique sont proposés par défaut ; vous pouvez choisir votre propre combinaison.

## Mise à jour depuis 0.1.0

Remplacer le dossier ou retélécharger avec HACS, puis redémarrer. Conserver l’entrée de configuration existante pour préserver les identifiants des dix entités déjà publiées.

## Validation et limites

14 tests du moteur, Hassfest et HACS passent sur le commit publié.
Home Assistant 2026.1 minimum ; 2026.3 minimum pour les images de marque locales.
Les académies ultramarines nécessitent une vérification des dates ; Nantes est la configuration testée.
Pas encore d’entités calendrier. Les jours ouvrés signifient lundi à vendredi hors jours fériés.
Le ZIP est un fichier d’installation manuelle ; le badge de téléchargements compte les fichiers joints aux releases, pas les installations.

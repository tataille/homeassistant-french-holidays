# French Holidays v0.1.3

## Améliorations

- Traduit les régions du formulaire selon la langue de Home Assistant.
- Remplace le titre anglais de l’étape de configuration par un titre français.
- Donne aux nouvelles entrées un titre plus lisible, composé de l’académie et du nom de région.

## Fiabilité

- Ajoute un test de non-régression vérifiant les deux compteurs de jours avant les vacances scolaires.

Les compteurs indiquent les jours restants selon leur définition respective. Home Assistant affiche l’unité `d` (« jour ») après leur valeur.

## Mise à jour

Installez la mise à jour depuis HACS ou remplacez le dossier `custom_components/french_holidays`, puis redémarrez Home Assistant. Conservez votre entrée de configuration existante.

# French Holidays v0.2.0

## Compatibilité HACS

- Renomme le domaine Home Assistant en `tataille_french_holidays` pour éviter le conflit avec une autre intégration déjà publiée dans le catalogue HACS.
- Retire l’image dupliquée du dossier de l’intégration ; les images de marque restent dans `brand/`.

## Migration depuis la version 0.1.x

Le domaine change. Supprimez l’ancienne entrée French Holidays et le dossier `custom_components/french_holidays`, puis installez la version 0.2.0 et ajoutez de nouveau l’intégration. Les entités seront recréées avec de nouveaux identifiants ; adaptez les cartes et automatisations qui utilisent les anciens identifiants.
